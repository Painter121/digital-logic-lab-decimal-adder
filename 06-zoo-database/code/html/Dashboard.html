📖 คู่มือการใช้งาน Zoo Management

🌟 ขั้นตอนการใช้งาน

  1. เพิ่มโซน (Zone)
    • โซนเป็นองค์ประกอบสำคัญของระบบ เพราะพนักงานและสัตว์ทุกตัวต้องมีโซนที่ประจำอยู่
    • ต้องกำหนด ชื่อโซน และ ความจุของพนักงานและสัตว์
    • สามารถ ขยายหรือลดความจุ ได้ภายหลัง
  2. เพิ่มพนักงาน (Employee)
    • พนักงานแต่ละคนต้องอยู่ในโซนที่กำหนด
    • หากโซนไม่มีพนักงาน จะไม่สามารถเพิ่มสัตว์ได้
  3. เพิ่มสัตว์ (Animal)
    • การเพิ่มสัตว์ต้องเลือกโซนที่มีพนักงานประจำอยู่
    • สัตว์แต่ละตัวจะถูกผูกกับโซน และไม่สามารถอยู่ในโซนที่ไม่มีพนักงานได้
  4. จัดการการดูแลสัตว์ (Animal Care)
    • กำหนดว่าพนักงานคนใดดูแลสัตว์ตัวใด
    • พนักงาน 1 คนสามารถดูแลสัตว์หลายตัว และสัตว์ 1 ตัวสามารถถูกดูแลโดยพนักงานหลายคน
    • พนักงานและสัตว์ต้องอยู่ในโซนเดียวกัน

⚠️ ข้อควรระวัง

  • ข้อจำกัดของโซน: โซนแต่ละแห่งมี ความจุจำกัด สำหรับพนักงานและสัตว์ แต่สามารถขยายหรือลดขนาดได้
  • การลบข้อมูล: ไม่สามารถลบพนักงานหรือสัตว์ได้ หากยังมีความสัมพันธ์ใน Animal Care ต้องลบข้อมูลความสัมพันธ์ก่อน
  • โซนอันตราย (RED ZONE): หากโซนไม่มีพนักงาน แต่ยังมีสัตว์อยู่ โซนนั้นจะกลายเป็น "RED ZONE" ต้องเพิ่มพนักงานหรือย้ายสัตว์ออก
